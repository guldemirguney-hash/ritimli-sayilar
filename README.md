# Ritimli Sayılar

7 yaş için sesli ritmik sayma yolculuğu (Vite + React + TypeScript).

    npm install
    npm run dev     # http://localhost:5173 (Chrome ile aç)
    npm test        # Türkçe sayı ayrıştırıcı testleri
    npm run build   # dist/ klasörü, Vercel için hazır

Mikrofon için https ya da localhost gerekir. Chrome, Edge ve Safari önerilir.
